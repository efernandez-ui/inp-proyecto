Quiero que implementes un sistema de filtros dinámicos para un catálogo e-commerce de repuestos de moto con la siguiente jerarquía obligatoria:

1) CATEGORÍA (tipo)
2) SUBTIPO
3) MARCA
4) ATRIBUTOS (dinámicos según categoría+subtipo)

ARCHIVOS DISPONIBLES
- filters_flat.json (estructura principal para saber qué filtros mostrar por categoría/subtipo)
- filters_config.json (opcional: labels y tipos sugeridos)
- Existe un listado de productos en JS (array products o similar) con al menos: tipo, subtipo, marca y atributos (objeto clave/valor)

REGLAS DE UI/UX Y LÓGICA
- El usuario primero elige Categoría. Hasta que no elija Categoría, los demás filtros deben estar deshabilitados.
- Al elegir Categoría, cargar el dropdown de Subtipo correspondiente a esa categoría.
- Al elegir Subtipo:
  - Habilitar el filtro Marca (solo si brandFilter = true para ese subtipo).
  - Renderizar los Atributos indicados en filters_flat.json[categoria][subtipo].attributes
- MARCA siempre va antes que ATRIBUTOS en la UI.
- Los valores (opciones) de Marca y de Atributos se generan desde los productos disponibles (valores únicos), pero SOLO considerando los productos que matchean el estado actual de filtros.
- Cada cambio de filtro recalcula:
  - el listado filtrado de productos
  - las opciones disponibles de los demás filtros (evitar opciones sin resultados)
- Debe existir un botón “Limpiar filtros” que resetee todo.
- Mostrar contador: “X resultados”.

REGLAS DE DATOS / MATCHING
- Comparación case-insensitive y trim para strings.
- Si un producto no tiene un atributo, NO debe contar como match cuando ese atributo está filtrado.
- Para atributos numéricos (si filters_config.json sugiere valueType=number o si detectás unidades mm/cm/cc/kg):
  - permitir filtro por rango (min/max)
  - si no es numérico, usar dropdown de valores únicos (string)

IMPLEMENTACIÓN SOLICITADA
- Crear un módulo/archivo filters.js (o equivalente) que exporte:
  - getCategories(filtersJson)
  - getSubtypes(filtersJson, category)
  - getFilterSchema(filtersJson, category, subtype) -> { brandFilter, productFilter, attributes[] }
  - getAvailableOptions(products, currentSelection, schema) -> { brands[], attributes: { attrName: values[] o {min,max} } }
  - applyFilters(products, currentSelection) -> filteredProducts[]
- Crear componentes UI (según el stack del proyecto):
  - Dropdown Categoría
  - Dropdown Subtipo
  - Dropdown Marca (si corresponde)
  - Atributos dinámicos (dropdowns y/o rangos)
  - Botón limpiar
  - Lista de productos resultante
- Asegurarse de que la jerarquía se respete estrictamente y que los filtros se encadenen correctamente.

NOTAS
- filters_flat.json define QUÉ filtros mostrar por categoría/subtipo; los valores (opciones) salen de products.
- No inventes categorías/subtipos: usar únicamente lo que viene del JSON.
- Si no hay productos para una combinación, mostrar “Sin resultados” y deshabilitar opciones no válidas.

Implementalo completo y funcional, con código limpio y comentarios breves.
Si el proyecto usa React, hacelo en React con estado local (useState/useMemo). Si es vanilla JS, hacelo con DOM y listeners.
